## 你选股票，联动啦帮你切行情

在开盘啦里发现一只股票，想去行情软件看看分时、K 线，不必再记代码、切窗口、重新搜索。

联动啦连接选股与看盘的操作：在电脑模拟器或安卓手机上点选开盘啦个股，电脑上的行情软件跟随切换；也可以使用双向模式，在通达信与同花顺之间切换个股。

## 三种使用方式

| 模式 | 怎么用 | 适合的场景 |
| :--- | :--- | :--- |
| **电脑联动** | 电脑模拟器中的开盘啦 → 通达信或同花顺 | 在电脑上一边选股、一边看行情 |
| **手机联动** | 安卓手机中的开盘啦 → 电脑行情软件 | 手机选股，电脑大屏看分时、K 线 |
| **双向联动** | 通达信 ↔ 同花顺 | 在两个行情软件之间对照查看个股 |

三个模式按需选择。正在联动时切换模式，程序会接续到新模式；手动停止后切换模式，仍保持停止。

### 一次启动，少几步操作

- **跟随最近操作的行情软件。** 电脑、手机模式下，同时打开多个行情软件时，跟随最近操作的目标；尚未操作时自动选择一个可用目标。
- **手机配对集中管理。** 切到手机模式，通过“手机配对”查看连接与配对信息。
- **按习惯选择是否返回。** 界面提供“联动后返回”选项。
- **常用操作放在一起。** 启动联动、模式选择、运行状态，打开界面就能找到。

## 开始使用

### 电脑联动

1. 从[官网](https://www.liandongla.com/)获取电脑版，打开通达信或同花顺。
2. 打开电脑模拟器中的开盘啦，选择联动啦的 **电脑** 模式。
3. 点击 **启动联动**，在开盘啦中点选个股。

### 手机联动

1. 安装电脑版和安卓手机版，让手机与电脑连接到可互通的同一局域网。
2. 在电脑端选择 **手机** 模式并启动联动，打开 **手机配对**。
3. 按页面提示完成手机端配对和必要权限设置，再在手机开盘啦中点选个股。

> 手机使用移动数据时，通常无法直接连接电脑的局域网地址。配对前请先检查 Wi-Fi 与电脑网络。

### 双向联动

1. 打开通达信和同花顺，并进入普通个股的分时或 K 线页面。
2. 选择 **双向** 模式并启动联动。
3. 在其中一端切换个股，查看另一端的跟随结果。

双向模式与电脑、手机模式独立运行，同一时间使用一个模式。具体版本与页面的适配情况，请以实际测试和官网说明为准。

## 常见问题

**手机联动还需要开电脑端吗？**  
需要。手机端传递选中的股票，电脑端负责切换行情软件。手机模式不需要运行电脑模拟器。

**同时开着通达信和同花顺，会一起切换吗？**  
电脑、手机模式跟随最近操作的行情软件。需要通达信与同花顺互相跟随时，请选择双向模式。

**支持哪些设备和行情软件？**  
电脑版用于 Windows，手机版用于兼容 Android APK 的设备。主要联动对象为通达信、同花顺；模拟器、系统、行情软件版本和页面差异可能影响使用，建议先试用确认。

**同花顺远航版可以用吗？**  
已加入远航版适配。建议在普通个股的分时或 K 线页面使用；不同版本、页面的表现需要实际验证，遇到问题可通过官网联系客服。

**在哪里下载、试用和购买？**  
统一通过[联动啦官网](https://www.liandongla.com/)获取安装包、试用说明与客服联系方式。版本、价格和服务说明以官网为准。

**连接失败或无法切股怎么办？**  
先确认模式已启动、行情软件已打开；手机模式还需确认两端网络互通。仍有问题时，请向客服提供软件版本、系统版本、行情软件名称以及报错截图，便于定位。
